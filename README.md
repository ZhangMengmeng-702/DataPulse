# DataPulse · 数据脉动

> 一个公开的数据可视化大屏项目

DataPulse（数据脉动）是一个用于构建实时数据可视化大屏的开源项目，旨在帮助开发者快速搭建美观、专业的数据展示界面。

## ✨ 特性

- 📊 丰富的可视化图表组件
- 🖥️ 自适应大屏分辨率，适配多种显示设备
- ⚡ 实时数据更新能力
- 🎨 现代化、科技感的设计风格
- 🔌 易于扩展与二次开发

## 🚀 快速开始

```bash
# 克隆仓库
git clone https://github.com/ZhangMengmeng-702/DataPulse.git

# 进入项目目录
cd DataPulse

# 安装依赖（待补充）
npm install

# 启动开发服务（待补充）
npm run dev
```
